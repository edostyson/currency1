# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1JIsoF_9vfGG1Qv_7KGIcwJfcnRevxmeY

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

This app uses the public Frankfurter exchange-rate API, so no API key is required.
